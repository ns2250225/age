# 记忆猜年龄（Memory Age Guess）

通过用户对不同年代流行事物的记忆，推断其年龄的趣味网页小游戏。纯前端实现：无需注册登录、无后端、不调用任何 AI 接口，题库随网页静态发布，推断完全在浏览器内完成。

需求文档见 [prd.md](prd.md)。

## 玩法流程

1. **自适应答题**：系统从题库（动漫、游戏、玩具、音乐、校园、互联网、生活、事件等类别）中按信息增益动态选题，每局题目都不同，最多 20 题，随时可选"不知道 / 没印象"。
2. **唯一一次猜测**：认为信息足够后，给出一个具体年龄；用户确认是否准确并可选填真实年龄（仅存本机 `sessionStorage`）。
3. **结果展示**：ECharts 后验概率分布图、支撑判断的记忆时间轴、可保存为图片的分享卡片（默认不展示真实年龄）。

页面路由：`/` 首页、`/rules` 规则、`/game` 答题、`/guess` 猜测与反馈、`/result` 结果、`/admin` 题库管理。

## 技术栈

- Vue 3 + TypeScript + Vite（hash 路由，`dist/` 可部署到任意静态目录）
- Pinia 状态管理（对局进度 `localStorage` 持久化，支持中断恢复）
- ECharts（年龄后验分布可视化）
- html-to-image + qrcode（分享卡片生成）
- 贝叶斯推断引擎（自研，见 `src/engine/`）

## 题库

修改 `scripts/generate-questions.mjs` 里的题目数据，然后：

```bash
npm run gen:questions
```

每道经历类题目只需填写“流行起止年份、经历年龄窗口、普及度、后世知名度、长辈知晓度”，脚本会据此生成各出生年份选择每个选项的概率。

两条出题原则（生成器会校验第二条）：

- **城乡/经济差异**：需要“买得起、当地有”的事物用 `acc`（可及度，0～1）标注。同龄人里只有这部分人接触得到，所以“没用过”不会被当成强年龄证据，这类题的可信度也相应降低。
- **不写“上学时/学生时代”**：题目必须写明小学、初中、高中或大学，年龄窗口与之对应。跨多个学段都有人经历的事物，问“流行的那几年你经历过吗”，并如实使用较宽的年龄窗口。
- **不出“那时候你在上什么学”这类阶段题**：等于变相问年龄。

**这些概率是按流行年份估算出来的，不是真实统计数据。** 上线后应按 PRD 第七章，用自愿、匿名的真实年龄反馈来校准（`src/utils/statistics.ts` 中已提供平滑公式和反馈计数的数据形态）。

## 推断算法

- 年龄范围 10～80 岁，均匀先验（可在 `src/engine/config.ts` 配置人口先验）。
- 每次回答在对数域做贝叶斯更新；证据按 `权重 × 可信度 × evidenceScale` 缩放，抑制相关题目造成的过度自信。
- “不知道 / 没印象”不产生任何证据。
- 选题：`Score = 信息增益 × 可信度 × 多样性`，在得分最高的几道题里加权随机，保证每局题目不同。
- 停止：最多 20 题；满 8 题且有 6 条有效回答后，最大概率 ≥ 0.35 或 80% 可信区间不超过 6 岁即停止；没有高价值题目时也停止。
- 最终只猜一次：取（轻度平滑后的）后验概率最高的年龄。

阈值均为初始值，需要用真实数据校准；页面上展示的“可能性”是模型内部的相对把握，不是准确率。

## 隐私

- 不收集任何个人信息，不发起任何数据上报请求。
- 答题进度存 `localStorage`（用于中断恢复）；真实年龄与反馈计数只存 `sessionStorage`。
- 本机准确率统计只保存聚合计数。
- 分享图片默认不展示真实年龄。
